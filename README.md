## libicns - vcpkg overlay port compatible with CMake

This repo contains an overlay port that I created to use the latest version of libicns (0.9.0 at the time of writing) in my C++ project.  I've developed a patch that allows compilation using CMake and the original GitHub repo, and it currently compiles on macOS and Linux successfully.
